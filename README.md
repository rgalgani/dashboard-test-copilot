# dashboard-test-copilot

Dummy single-page HTML dashboard for a UN mental health M&E project in Somalia. This repository contains client-side HTML, CSS and JS using Chart.js and Leaflet with generated dummy data.

Files added:
- index.html — main dashboard
- styles.css — CSS
- data.js — dummy data tailored to a UN mental health M&E scenario
- scripts.js — chart and map rendering logic
- assets/un-logo.svg — placeholder UN-style logo

How to run
1. Clone the repo or download files.
2. Open `index.html` in a web browser (no server required).

Notes
- All data is dummy and for demonstration only. Replace `data.js` with real M&E data to adapt to production.
- Map uses OpenStreetMap tiles and simple marker circles to indicate service coverage.
